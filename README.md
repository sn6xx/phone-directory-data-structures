# Phone Directory Application (Data Structures Project)

## Project Introduction

### Overview
This project focuses on developing a phone directory application using two fundamental data structures: a linked list and a stack.

The linked list is used to store and manage contacts efficiently, allowing easy insertion, deletion, and retrieval of contact information. The stack is used to track the user's search history. Every time a user searches for a contact, the result is pushed onto the stack, allowing quick access to previous searches.

---

### Problem and Solution
Managing a growing list of contacts can become complex and inefficient using traditional methods.

This project provides a solution by:
- Using a **Linked List** to manage contacts dynamically.
- Using a **Stack** to store and track search history.

This combination improves both performance and usability.

---

### Solution Justification
The use of a linked list allows flexible and efficient contact management without fixed size limitations.

The stack enhances user experience by:
- Keeping track of previous searches
- Allowing quick retrieval of recent search operations

Together, these data structures provide a simple and efficient solution for managing contact information.

---

## Features
- Add new contacts
- Delete contacts
- Display all contacts
- Search by phone number
- Filter contacts by gender
- Track search history using stack
- Count how many times a number was searched
- Display most recent search
- Delete search history
